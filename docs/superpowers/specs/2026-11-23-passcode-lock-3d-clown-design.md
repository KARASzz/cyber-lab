# 前端九宫格安全密码锁与小丑 3D 翻转动效设计规范

- 日期：2026-11-23
- 状态：已确认 (Approved)
- 目标：在 CYBER//LAB 首页构建入口级强阻断安全门禁，九宫格键盘输入固定密码 2580 解锁；输错触发 3D 顺时针翻转至小丑纯图，点击小丑继续同向翻转 180° 复原并重置；主站提供锁定退出入口。

---

## 1. 核心需求与设计约束

### 1.1 入口强阻断 (Fail-Closed)
- 未解锁前，页面展示全屏遮罩居中门禁卡片 `#lab-lock-screen`。
- 主站 DOM `#lab-app` 设置 `inert` 属性和隐藏，键盘及辅助设备无法探测内部结构。
- 严禁在解锁前发起任何云端或后端网络请求（包括 `/api/lab/workspace`、`/api/chat`、自动同步）。
- 固定密码硬编码为 `2580`。

### 1.2 3D 翻转与小丑纯图
- 卡片视口：`perspective: 1200px`。
- 翻转容器：`transform-style: preserve-3d; transition: transform 0.75s cubic-bezier(0.4, 0, 0.2, 1);`。
- 正面（九宫格键盘）与背面（小丑纯图）均设置 `backface-visibility: hidden`。
- 输错密码（满 4 位且非 2580）时：沿 Y 轴平滑顺时针翻转 180°（`rotateY(0deg) -> rotateY(180deg)`）。
- 背面严禁出现任何文字、说明或按钮，纯粹为一张 1:1 马戏团小丑插画（深黑底色、红鼻、发光警示外框）。
- 小丑本身即为点击热区，悬停鼠标显示 `cursor: pointer` 并微放大。
- 点击小丑后：继续沿顺时针同向翻转 180°（`rotateY(180deg) -> rotateY(360deg)`）。
- 动画完成后（`transitionend`）瞬间重置为 `0deg` 并清空输入缓冲区。

### 1.3 会话认证与全局锁定
- 验证通过后写入 `sessionStorage['cyberlab.unlocked'] = '1'`，淡出门禁遮罩，解除 `#lab-app` 阻断，启动主站数据拉取与初始化。
- 顶栏右上角提供「🔒 锁定工作台」按钮，点击立即销毁会话认证态，切回门禁卡片。
